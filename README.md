# 学习周报生成器

把「虚拟自习室」「拾题·考研错题本」「考研资料管家」三个工具的导出数据汇总成一份 Markdown 周报。

## 使用方式

直接双击打开 `index.html`（或部署到任意静态托管）。

1. **导入数据**（可全部或任选）：
   - 虚拟自习室：`专注统计 → 导出数据(JSON)`
   - 错题本：`今日复习 → 导出备份`
   - 资料管家：`同步` 生成的同步包 JSON
   - 822考研引擎：`进度统计 → 导出学习报告(.md)`
2. 选择周次（默认本周，可回看历史周）。
3. 点击「生成周报」→ 预览、复制或下载 `.md`。

## 周报内容

- 📊 专注情况：总时长、次数、最高效日、科目分布
- ✅ 任务与复盘：完成任务数、每日复盘数
- 📝 错题情况：新增错题、复习题次、薄弱科目
- 🗂️ 资料整理：资料总数、已整理数、科目分布
- ⚙️ 822 控制学习：模块掌握度（来自 822 引擎报告）
- 🎯 本周小结

## 隐私

全部数据仅在浏览器本地处理，不上传任何服务器，无外部依赖。

## 数据格式说明

| 来源 | 关键字段 |
|---|---|
| 自习室 | `focusSessions[]`（date/duration/subjectName/timestamp）、`tasks[]`、`dailyReviews[]` |
| 错题本 | `questions[]`（createdAt/reviewHistory/reviewCount/subject）、`done{}`（日期→id数组） |
| 资料管家 | `items[]`（time/status/subject）、`log[]` |
